# Vela VPN — релизы

Здесь публикуются подписанные APK приложения Vela.

## Установка

1. Скачайте APK из раздела **Releases**.
2. Разрешите установку из этого источника, если Android попросит.
3. Обновления приложение получает само: сервер отдаёт ссылку на последний релиз,
   APK проверяется по SHA-256 перед установкой.

## Сборки

APK собираются под ARM — `arm64-v8a` и `armeabi-v7a` (все современные телефоны).
Эмуляторы x86 не поддерживаются: так файл весит 65 МБ вместо 102 МБ.

## Подпись

Все сборки подписаны одним и тем же ключом, поэтому обновления ставятся поверх
предыдущей версии без удаления данных.
